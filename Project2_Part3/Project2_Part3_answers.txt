According to the kit information, the libraries incorporate dUTP during the second strand synthesis step. This indicates that during amplification, the second strands are degraded since they are the ones with the dUTP.
Therefore, this library is first strand cDNA. According to the article provided, "First strand cDNA libraries require the use of the stranded ‘Reverse’ option for RNA-Seq workflow using the htseq-count tool." This means that
the library we are using requires the stranded=reverse option. The counts above support that, because the reverse runs have much higher proportions of mapped reads than the yes runs. According to the paper, when the htseq tool
was written, it was more common for libraries to be second strand specific, which is why the default stranded option for htseq-count is "yes". Newer, more recent kits have switched to first strand specific and therefore require
the reverse option.
